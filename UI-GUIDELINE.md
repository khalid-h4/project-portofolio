# UI/UX Design Guideline
## Theme: Modern Futuristic Dark SaaS Dashboard

### 1. Palet Warna Brand (Cyberpunk Dark Neon)
- Background Utama: `#0B0F19`
- Card / Surface: `#111827` (Dark Slate Glassmorphism)
- Accent Primary (Merah): `#EF4444`
- Accent Secondary (Orange): `#F97316`
- Accent Highlight (Kuning Neon): `#EAB308`
- Accent Cool (Biru Glowing): `#3B82F6`

### 2. Tipografi & Layout
- Font Family: `Plus Jakarta Sans`, sans-serif.
- Layout: Responsive 12-Column Grid dengan Tailwind CSS.
